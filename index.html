Install on your home screen

iPhone or iPad
Tap Share, select “Add to Home Screen”, then tap “Add.”
Android using Chrome
Tap the three-dot menu ⋮, select “Install app” or “Add to Home screen,” then tap “Install” or “Add.”
Samsung Internet
Tap the menu ☰, select “Add page to,”, then select “Home screen.”

Install this launcher while this page is visible. Do not open the Apps Script page before installing if you want to keep the customized PCCU icon.
